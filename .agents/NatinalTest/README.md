# Mobile Vocabulary Memorization App

## Project Overview (For Judges)

This project was developed following a structured agent‑based guideline (`agents.md`)
designed specifically for **international programming competition standards**.

The primary objective was to fully satisfy all functional requirements and scoring criteria
with a **stable, reproducible implementation (Phase 1)**, then refine the codebase for
**clarity and responsibility separation (Phase 2)**, and finally optimize documentation
and evaluation flow for judges (**Phase 3**).

All design decisions were intentional:
- Correctness and requirement compliance were prioritized over speculative features.
- Code structure reflects clear responsibility boundaries rather than unnecessary abstraction.
- Failure scenarios are handled gracefully to prevent application crashes.

---

## Key Features

- User authentication (Sign Up / Sign In / Sign Out)
- Personal vocabulary management (CRUD)
- User‑isolated data storage
- Stable navigation flow
- Explicit loading and error handling
