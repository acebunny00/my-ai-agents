# 문제 해결 가이드.md

## 1. 문제 이해

- 개인별 단어를 관리하는 모바일 어휘 암기 앱 구현
- 인증 기반 사용자 분리 필수

---

## 2. 해결 전략

### Phase 1
- 필수 기능 구현
- 채점 기준 100% 충족

### Phase 2
- 코드 가독성 및 책임 분리 개선

### Phase 3
- 심사 친화적 문서화

---

## 3. 구현 순서

1. 프로젝트 생성
2. 인증(Auth) 구현
3. 데이터 모델 정의
4. 단어 CRUD 구현
5. 네비게이션 분리
6. 에러/로딩 처리

---

## 4. 최종 점검

- 기능 정상 동작 여부
- 다른 사용자 데이터 접근 불가
- 앱 크래시 없음
